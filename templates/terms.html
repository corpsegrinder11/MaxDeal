Términos y Condiciones

Última actualización: Septiembre 2026

1. Servicios

MaxDeal ofrece servicios de desarrollo web y automatización de WhatsApp para emprendedores. Los servicios incluyen:

  • Desarrollo de landing pages profesionales
  • Automatización de respuestas de WhatsApp Business
  • Desarrollo de páginas web completas (hasta 5 secciones)
  • Soporte técnico post-entrega

2. Proceso de Trabajo

El flujo de trabajo es el siguiente:

  1. Orden del servicio: El cliente selecciona y paga el 50% de anticipo del servicio.
  2. Llamada de inicio: Se agenda una llamada de 20 minutos para entender el negocio y necesidades.
  3. Desarrollo: MaxDeal trabaja en el proyecto durante el tiempo estimado (48-72 horas para landing pages, 5-7 días para webs completas).
  4. Revisión: El cliente revisa el trabajo y puede solicitar ajustes menores.
  5. Entrega final: Una vez aprobado, el cliente paga el 50% restante y recibe los archivos/acceso.

3. Tiempos de Entrega

Los tiempos de entrega son estimados y pueden variar según:

  • Complejidad del proyecto
  • Tiempo de respuesta del cliente para feedback
  • Cantidad de revisiones solicitadas

Tiempos estimados:

  • Landing Page: 48-72 horas hábiles
  • Automatización WhatsApp: 24-48 horas hábiles
  • Página Web Completa: 5-7 días hábiles

4. Pagos

Los pagos se realizan de la siguiente forma:

  • 50% de anticipo: Al momento de ordenar el servicio
  • 50% restante: Al aprobar el trabajo final

Métodos de pago aceptados:

  • Transferencia bancaria (Chile)
  • PayPal (internacional)
  • Otras plataformas a convenir

5. Revisiones y Ajustes

Cada servicio incluye:

  • 1 semana de soporte: Para ajustes menores después de la entrega
  • Ajustes mayores: Se cotizan por separado con precio preferencial

Se consideran ajustes menores: cambios de texto, colores, imágenes, espaciado. Se consideran ajustes mayores: cambios de estructura, funcionalidades nuevas, rediseño completo.

6. Garantía

MaxDeal ofrece garantía de satisfacción:

  • Si el cliente no está satisfecho con el trabajo final, puede solicitar ajustes dentro de la primera semana
  • Si después de los ajustes el cliente sigue insatisfecho, puede solicitar reembolso del 50% pagado (solo si no ha habido uso comercial del trabajo)

7. Propiedad Intelectual

Una vez pagado el 100% del servicio:

  • El cliente es dueño del diseño y código desarrollado
  • MaxDeal se reserva el derecho de mostrar el trabajo en su portafolio (a menos que el cliente solicite confidencialidad por escrito)

8. Hosting y Dominio

Para servicios que incluyen hosting:

  • El hosting está incluido por 12 meses
  • Después del primer año, el cliente puede renovar con MaxDeal o migrar a otro proveedor
  • El dominio es propiedad del cliente (MaxDeal ayuda con la configuración)

9. Automatización de WhatsApp

Para servicios de automatización:

  • El cliente debe tener una cuenta de WhatsApp Business activa
  • MaxDeal configura la automatización pero no se hace responsable por bloqueos de WhatsApp
  • El cliente recibe manual de uso y acceso a la configuración

10. Limitación de Responsabilidad

MaxDeal no se hace responsable por:

  • Pérdidas de ventas o ingresos del cliente
  • Problemas con terceros (hosting, dominio, WhatsApp, etc.)
  • Mal uso de las herramientas entregadas
