Política de Privacidad

Última actualización: Septiembre 2026

1. Información que Recopilamos

MaxDeal recopila la siguiente información de los clientes:

  • Datos personales: Nombre completo, email, teléfono, RUT/DNI
  • Datos de facturación: Nombre, dirección, ciudad, país, código postal
  • Datos de pago: Información de tarjeta (procesada de forma segura, no almacenada)

2. Cómo Usamos tu Información

La información recopilada se usa para:

  • Procesar y entregar los servicios contratados
  • Enviar facturas y comprobantes de pago
  • Comunicación sobre el estado del proyecto
  • Soporte técnico post-venta
  • Mejorar nuestros servicios (feedback)

3. Protección de Datos

MaxDeal toma en serio la seguridad de tus datos:

  • Los datos se almacenan de forma segura y encriptada
  • Solo el desarrollador tiene acceso a la información
  • No se comparten datos con terceros (excepto procesadores de pago necesarios)
  • Los datos de pago se procesan directamente por la pasarela (no pasan por nuestros servidores)

4. Cookies y Tracking

Este sitio web usa:

  • Cookies esenciales: Para funcionamiento del carrito y sesión
  • Google Analytics (opcional): Para entender cómo los visitantes usan el sitio (puedes desactivarlo)

5. Tus Derechos

Como cliente, tienes derecho a:

  • Acceder a tu información personal
  • Corregir datos incorrectos
  • Solicitar eliminación de tus datos (después de completar el servicio)
  • Oponerte al uso de tus datos para marketing

6. Retención de Datos

Conservamos tus datos mientras:

  • El servicio esté activo
  • Existan obligaciones legales o fiscales
  • Sea necesario para soporte post-venta

Después, los datos se eliminan de forma segura.

7. Terceros

Podemos compartir información con:

  • Procesadores de pago: Para procesar transacciones (ej: Stripe, PayPal)
  • Proveedores de hosting: Para alojar tu sitio web (solo datos necesarios)
  • Autoridades: Si es requerido por ley

8. Cambios a esta Política

Podemos actualizar esta política ocasionalmente. Los cambios se publicarán en esta página con la fecha de actualización.

9. Ley Aplicable

Esta política se rige por las leyes de Chile. Para clientes internacionales, se respetan las leyes locales de protección de datos.
