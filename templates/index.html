Sí. El trabajo se realiza de forma remota para clientes de Chile y otros países de Latinoamérica. El método de pago se define según el país.

La publicación inicial está incluida según el alcance acordado. El dominio se registra a tu nombre y los costos de renovación se explican antes de contratar para que no haya sorpresas.

Incluyo una semana para ajustes menores posteriores a la entrega. Si luego necesitas nuevas secciones, funciones o una evolución mayor, se cotiza aparte y siempre se confirma antes de realizar el trabajo.

Se reserva con un 50% de anticipo una vez confirmado el alcance. El 50% restante se paga al aprobar la entrega. No se almacenan datos de tarjeta en este sitio.
