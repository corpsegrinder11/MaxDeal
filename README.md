# MaxDeal

Landing de un solo producto con Flask + HTML/CSS/JS nativo.

## Estructura

- backend/: Flask app, config, logs, utils.
- frontend/: Templates y estáticos.
- emails/: Plantillas de correo.

## Ejecución

cd backend
python -m venv venv
source venv/bin/activate
pip install -r requirements.txt
python app.py

Abre http://localhost:5000
